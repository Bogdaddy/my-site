Підготовка

Встановіть ПЗ до першого уроку

Оберіть свій напрямок і встановіть всі програми заздалегідь — на уроці відразу почнемо писати код.

1
Unity Hub Безкоштовно
Менеджер для встановлення Unity. Завантажте спочатку його — він керує всіма версіями.
↗ unity.com/download
2
Unity LTS Безкоштовно
Через Unity Hub встановіть версію Unity LTS (Long Term Support) — вона найстабільніша. Шукайте мітку LTS у списку версій.
3
Visual Studio 2022 Community Безкоштовно
Під час встановлення обов'язково оберіть розширення «Розробка ігор за допомогою Unity» (Game development with Unity) — воно додає всі потрібні інструменти для C#.
↗ visualstudio.microsoft.com
4
Unity ID Безкоштовно
Зареєструйтесь на unity.com — без цього Unity не запуститься. Займе 2 хвилини.
↗ id.unity.com
5
Discord Безкоштовно
Для проведення уроку онлайн — демонстрація екрану та голосовий зв'язок. Встановіть додаток (не веб-версію) для стабільної роботи.
↗ discord.com/download
1
Python 3.10+ Безкоштовно
Завантажте з офіційного сайту. При встановленні обов'язково поставте галочку «Add Python to PATH» — без неї нічого не запуститься.
↗ python.org/downloads
2
Visual Studio 2022 Community Безкоштовно
Під час встановлення оберіть розширення «Розробка на Python» (Python development) — воно підключить всі потрібні інструменти, автодоповнення та дебагер.
↗ visualstudio.microsoft.com
3
GitHub Безкоштовно
Зареєструйтесь — зберігатимемо тут ваш код та домашні завдання. Також зручно ділитися проектами.
↗ github.com
4
Discord Безкоштовно
Для проведення уроку онлайн — демонстрація екрану та голосовий зв'язок. Встановіть додаток (не веб-версію) для стабільної роботи.
↗ discord.com/download
